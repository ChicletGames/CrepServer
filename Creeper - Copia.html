Regras do Servidor

🤝

1. Respeito Mútuo

Respeita todos os jogadores no chat. Ofensas pesadas, preconceito e toxicidade não serão tolerados.

🚫

2. Proibido Hacks / Cheats

O uso de x-ray, auto-clickers ou clientes modificados resultará em banimento permanente.

⚖️

3. Fair Play & Convivência

Mantém um jogo limpo. O aproveitamento de bugs ou atitudes antidesportivas para prejudicar a comunidade levará a punição.

📜 Comandos para Jogadores

🏡 Terrenos e Proteção

/trust <jogador>Dá permissão total de acesso ao teu terreno para um amigo.
/untrust <jogador>Remove as permissões de um jogador no teu terreno.
/claimslistMostra a lista de todos os teus terrenos e blocos disponíveis.
/abandonclaimApaga o terreno onde estás em cima.
/trappedTeleporta-te para fora de um terreno caso fiques preso.

🚀 Teleporte e Casas

/tpa <jogador>Envia um pedido para te teleportares até um jogador.
/tpacceptAceita um pedido de teleporte pendente.
/sethome <nome>Guarda a tua localização atual como uma casa.
/home <nome>Teleporta-te para uma das tuas casas salvas.
/homesAbre o menu com todas as tuas casas.

🏰 Clãs

/clan create <nome>Cria o teu próprio clã.
/clan invite <jogador>Convida um jogador para o teu clã.
/c <mensagem>Envia uma mensagem no chat privado do teu clã.

🛒 Economia & Mercado

/shopAbre o menu da loja do servidor.
/sellallVende todos os itens elegíveis do teu inventário.
/nightmarketAbre o Mercado Noturno com ofertas rotativas.

👕 Skin & Conta

/skin <nome>Altera a tua skin para a de um jogador Java original.
/register <senha> <senha>Regista a tua conta na primeira vez que entras.
/login <senha>Faz login na tua conta ao entrar no servidor.
